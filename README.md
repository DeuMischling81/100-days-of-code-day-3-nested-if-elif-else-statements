# Day 3 - Nested if/elif/else statements

In day 3, I learned about nested if/elif/else statements, and how to had additional conditional statements inside of a main conditional statement. Using this knowledge we had to write an if/elif/else statement that would allow us to determine if someone is eligible to ride on a roller coaster, and what their fare price would be based on their age.


In day 3, I also learned about the modulo operator, and how to write code that verifies if a number is even or odd, when evaluated against a modulo operator.

Day 3 also included Multiple Ifs statements, where we have to incorporate different conditions that are unrelated to each other. Using that information, the check on learning was to update the roller coaster code, and add an additional if statement to see if they would be interested in having a picture taken. This would then be included in the overall price of the fare.
